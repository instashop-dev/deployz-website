- `deployz-product-walkthrough.mp4`: 1920 x 1080, about three minutes, with local synthetic narration and an English subtitle track.
- `deployz-social-30s-square.mp4`: 1080 x 1080, 30 seconds, silent, with the message shown on screen.
- `deployz-walkthrough.srt` and `deployz-walkthrough.vtt`: captions for platforms that need a separate file.

- `scene-*.svg` and `scene-*.png`: editable scenes and rendered frames.

The walkthrough contains a real configuration capture and labelled architecture illustrations. It is not a recording of a new live AWS installation. The account had no active deployments, and the selected test app had no available release to share. No new release, AWS resource, or customer installation was created for this material.

The narration uses the installed Microsoft Zira Desktop voice. The recording does not impersonate a person. Captions follow the narration. Use the SRT or VTT file when a platform removes embedded subtitles.
