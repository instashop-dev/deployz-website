## Start here

1. Read the plan and claims file.
2. Assign an owner in the tracker.
3. Check the live product, prices, and links.
4. Replace email fields in square brackets.
5. Use the walkthrough as labelled. Record a full live demo only when a test release and approved AWS account are available.
6. Review each asset before publication.
7. Record results each week.

Week numbers start when the campaign starts. They are not calendar dates. Budget, team capacity, and baseline results are not yet known. The plan assumes one owner and uses existing channels without paid ads.

The kit contains no blog drafts. Read `../docs/DEPLOYZ_BLOG_MASTER_GUIDELINES.md` before you add blog work.
