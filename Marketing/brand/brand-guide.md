# Deployz brand asset guide

Use the original black Deployz symbol on a white or light neutral surface. The source is `../../public/deployz-icon-master.svg`. Copies in this folder preserve the source shape.

## Files

- `deployz-symbol.svg`: original vector symbol.
- `deployz-symbol-512.png`: transparent raster export.
- `deployz-wordmark.svg`: symbol with lowercase deployz text, made with the website layout.
- `deployz-wordmark.png`: transparent raster export of that layout.
- `tokens.json`: colors, font, and destination links.
- `inter-latin-variable.woff2`: local Inter web font copied from the installed package.
- `OFL.txt`: Inter font license copied from the package.

## Design rules

Use white #FFFFFF for the main background. Use #111111 for main text, #52525B for body text, and #2563EB for links or a small point of emphasis. Use #E4E4E7 for fine borders. Keep generous space around the content.

Use Inter. Use sentence case and short, direct headings. Use system monospace only for technical values.

Keep the symbol's proportions. Do not redraw, rotate, stretch, recolor, add a shadow, or put the mark in a decorative tile. No approved inverse logo is supplied. Do not place the black mark on a dark background.

The wordmark uses the site's symbol and lowercase text layout. It is an export of that layout, not a new symbol design.

For social graphics, use the supplied SVG as the editable source and PNG as the publication file. Use alt text from `../social/captions-and-alt-text.md`. Check prices before using the pricing graphic.

For product pictures, distinguish live captures from illustrations. Keep the label with the image. Do not add invented customer counts, review scores, or certification badges.
